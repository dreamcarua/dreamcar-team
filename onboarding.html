ЛАСКАВО ПРОСИМО У КОМАНДУ

DreamCar — українська платформа де люди купують токени ШІ-сервісу, а серед учасників розігруються автомобілі мрії. 17 авто з 2019. База 100k+ учасників. Наша команда — це люди + системи: ми побудували один інструмент, де ВСІ працюють разом без хаосу.

💡 Що ти знайдеш тут

За 30-40 хвилин ти знатимеш:

  • Як працює HQ — місце де народжуються всі публікації
  • Як працює Tasks — звідки беруться задачі, як їх закривати
  • Що відбувається з твоїми фото та відео після завантаження
  • Як пости автоматично потрапляють у TG-канал, Instagram, Facebook, Threads
  • Які сповіщення ти будеш отримувати — куди, коли, як на них реагувати
  • Як TG-бот @dreamcar_team_bot допомагає працювати без HQ

🎯 Принцип №1: Робота тече сама

Ми побудували все так, щоб ти приймав рішення, а система робила рутину. Натиснув «На погодження» → approvers одразу побачать у TG. Approved → пост сам полетить у канал у потрібний час. Кинув фото → стиснулось і готове.

/// СИСТЕМА 01

HQ — ЦЕНТР ПУБЛІКАЦІЙ

Тут живе ВСЕ що публікується. Календар, картки публікацій, погодження, шаблони, AI-помічник.

💡 Що це робить

HQ замінив 5 інструментів (Excel + Google Docs + TG-чат + Slack + ручний постинг) на одну сторінку. Усі публікації — тут. Від ідеї до того моменту як підписники побачать пост.

Дані оновлюються real-time. Хтось редагує паралельно — ти бачиш зміни без F5.

🎬 Як це працює — flow

Кожна публікація проходить 4 статуси:

  1. draft — SMM пише, прикріплює креатив. Авто-сейв.
  2. review — натиснув «На погодження». Approvers отримують TG DM з ✅/↩.
  3. approved — ВСІ approvers погодили. У чергу на постинг.
  4. published — пост у каналі. Видно посилання.
SMM

Як створити публікацію

  1. HQ → клік на дату у календарі (або «+ Створити»)
  2. Заголовок + текст (⚡ AI Copy — 3 варіанти у нашому стилі)
  3. Обери платформи
  4. Перетягни креативи з Бібліотеки
  5. Постав час публікації
  6. Обери approvers
  7. «На погодження» — далі система працює сама
💡 AI Copy знає наш voice DreamCar (без «квитків/розіграшів/лотерей» — юридичні ризики, коротко).
APPROVER

Як погодити — 3 способи

  1. TG inline: DM від @dreamcar_team_bot → ✅
  2. HQ UI: Дошка погоджень → «Погодити»
  3. /approve у боті: черга всіх постів
⚠️ Multi-approver AND: статус «approved» тільки коли ВСІ погодили.
APPROVER

Як повернути на rework

  1. ↩ у TG inline (двокроковий: причина → confirm)
  2. Або у HQ «Повернути» → модалка з категоріями
  3. SMM одразу отримає TG DM з причиною
  4. У Tasks автоматично створюється задача (due = +1 день)
SMM

Корисні трюки

  • Дублювати на платформу — один пост → дублі для TG/IG/FB
  • Шаблони — повторювані типи постів
  • Per-platform date/time — різний час одним постом
  • Bulk delete + undo — 5 сек на скасування
  • Cmd+K — глобальний пошук

🔍 Де результат

Після того як пост запостився — у HQ зʼявляється посилання на TG-повідомлення. Клік → відкривається пост у каналі.

/// СИСТЕМА 02

TASKS — ЗАДАЧІ КОМАНДИ

Все що НЕ публікація: операційне, бюджети, переговори, баги.

💡 Що це робить

Кожна задача має одного власника, дедлайн, пріоритет (P1-P4), watchers, автоматичні нагадування.

Звідки беруться задачі:

  • Lead/COO створив і призначив тобі
  • Ти створив сам собі (todo)
  • Авто-задача з HQ — коли пост повернули на rework
  • Recurring — «Щотижневий звіт» сам зʼявляється
ВИКОНАВЕЦЬ

Як закрити задачу

  1. Tasks → клік на свою задачу → Overview
  2. «Розпочати» → status: doing
  3. Subtasks галочками
  4. «Завершити» → status: done
  5. Recurring → наступна автоматично
💡 З TG: під нотифікацією — ✅ Виконано / 💬 Коментар / ⏰ +1 день.
LEAD / COO

Як створити задачу

  1. Tasks → «+ Нова задача»
  2. Заголовок на дію («Зробити Х»)
  3. Assignee — одна людина
  4. Priority (P1=критично, P4=коли буде час)
  5. Due date — реалістичний дедлайн
  6. Save → assignee отримає TG DM
LEAD / COO

Templates

Однотипну задачу — зроби template один раз. Tasks → Templates → «+ Новий шаблон» → опиши → «+ Нова з шаблону» = заповнено.

📊 Аналітика

/tasks/analytics.html: KPI, chart по днях, P1/P2/P3/P4, per-assignee load, avg time-to-done, bottleneck detection.

📡 Сповіщення

  • Призначили задачу — TG DM + Email
  • Коментар з @mention — TG DM
  • Прострочено — TG DM (раз на день о 9:00)
/// СИСТЕМА 03

КРЕАТИВИ — ФОТО ТА ВІДЕО

Як завантажувати, чому інколи спінер крутиться.

💡 Як працює стиснення

Сирі відео — 100-500MB. Telegram приймає ≤50MB. Ми автоматично стискаємо у фоні. Якість максимальна, тільки розмір зменшуємо.

Тобі це невидиме. 200MB → за ~3 хв стало 49MB → готове.

SMM / DESIGNER

Як завантажити креатив

  1. HQ → Бібліотека
  2. «+ Завантажити» або перетягни файли
  3. Підтримуються: JPG, PNG, HEIC, MP4, MOV, WebM
  4. Файл йде у Cloudflare R2
  5. З'явиться зі спінером 🌀
  6. Через ~3 хв спінер зникне — креатив ready
💡 Можна перетягувати декілька файлів одразу.

🔍 Стани креативу

ІконкаСтанЩо значить
🌀pending / processingСтискається. ~3 хв.
✅readyГотовий.
⚠️failedНе вдалося. Перезавантаж.
—n/aНе потребує стиснення.
⚠️ HEIC iPhone підтримуються — конвертуються у JPG автоматично.
/// СИСТЕМА 04

АВТОПОСТИНГ

Approved пости летять у канали самі. Ти не маєш постити руками.

💡 Як працює

Всі approvers погодили → публікація у черзі. Якщо час уже настав — піде через ~30 сек. У майбутньому — почекає до часу.

Telegram канал DCSMM — живий.

Instagram, Facebook, Threads — Phase 2 (код готовий, чекаємо Meta App).

🎬 Приклад: запланувати на завтра

  1. HQ → publish_at = 2026-05-30 14:00 CEST
  2. Approvers погодили сьогодні → у черзі
  3. Завтра о 14:00 worker візьме і опублікує
  4. За -10 хв команда отримає reminder у TG-групу
  5. За +10 хв перевірка чи постнулось

🔍 Де подивитись

  • У HQ біля approved-поста — посилання на TG
  • Канал DCSMM напряму
  • HQ → Аналітика V3 → funnel
⚠️ Пост «застряг» >30 хв: перевір що креатив у ready + publish_at не у майбутньому + напиши Вадиму.

/// ЧАСТІ ПИТАННЯ

FAQ — ПИТАЛИ НАЙЧАСТІШЕ

Чому не приходять TG-сповіщення?

1) /start у @dreamcar_team_bot.
2) HQ Settings → Notifications → TG увімкнено.
3) TG-bind індикатор червоний — пере-bind через /start.

Як змінити час публікації після approve?

Якщо ще не опубліковано — зміни publish_at → save. Якщо змінив >10 символів у тексті — авто-revert у review.

Де подивитись чи мій пост опублікувався?

У HQ біля поста — посилання на TG. Або відкрий канал DCSMM напряму.

Я завантажив відео — чому довго крутиться?

Compress queue — кожні 3 хв опрацьовує один файл. 10 файлів = ~30 хв. >1 год — пиши Вадиму.

Як скасувати дію? Я видалив за помилку.

Undo delete — кнопка на 5 секунд внизу. Якщо минуло — пиши Вадиму.

Не хочу DM під час відпустки.

HQ → Settings → Vacation mode → дати + делегат.

Що таке P1-P4?

P1=критично (сьогодні), P2=цього тижня, P3=місяць, P4=коли буде час.

Як працює recurring задача?

Обери recurrence. Закриваєш → наступна автоматично.

Я бачу не всі функції — це нормально?

Так. Обрав роль і показано тільки релевантне. «змінити роль» у sidebar — побачиш інше.
