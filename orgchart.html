# Функція / Роль Поточний стан Вплив на бізнес Пріоритет
1 Marketing Manager Виконує Вадим (~40% часу). Немає системи, все ситуативно Вадим не може масштабувати. Контент без плану = нижчі продажі 🔴 ПЕРШИЙ найм
2 Ads Manager (Meta) Вадим основний, Оборот — неефективний підрядник Без спеціалізованого фахівця гроші на рекламу витрачаються неефективно 🟡 Другий крок
3 Роль Вови Друг, зацікавлений, але без чіткої задачі і KPI TikTok — великий канал, але без відповідальної людини = нуль результату 🟡 Визначити або вивести
4 Звітність Артема Немає шаблонів, процес не описаний, затримки Нема контенту після проекту = втрата вірусного потенціалу 🟡 Вирішується регламентом
5 Бухгалтер / юрист Вадим робить сам Ризик помилок при масштабуванні. Зараз некритично 🟢 На майбутнє

⟶ Наступні кроки

  1. Скласти профіль ролі Marketing Manager — функції, зону відповідальності, KPI, вимоги до кандидата
  2. Вирішити питання Вови — дати конкретну задачу на наступний проект (#17) з вимірюваним результатом
  3. Закрити питання Оборот — проаналізувати CPL за 3 останні проекти та прийняти рішення
  4. Визначити канали пошуку Marketing Manager — Djinni, LinkedIn, референс від знайомих, Ukrainian marketers спільноти
