/// Цикли запусків — порівняння
Метрики по кожному циклу розіграшу (пости в межах дат проєкту) + продажі циклу. Порівнюй цикл-до-циклу. Виручка = ВСІ оплати циклу (всі канали), не атрибуція IG.

Охоплення циклу ↔ продажі

Чи сильніші за охопленням органічні цикли = більші продажі. Directional-кореляція (канали змішані), не атрибуція. Розмір точки = постів.

Охоплення: розподіл постів

Частота vs залученість (контекст)

/// Reels-скоркард

Hold-rate (% перегляду від тривалості) недоступний — IG Graph API не віддає тривалість reel. Орієнтир: середній перегляд + повтори + plays/reach.

/// Stories

Stories збираються лише вперед (IG віддає активні ~24 год), тож історії немає — статистика накопичуватиметься з сьогодні.

/// Power-пости (saves × sends)
Верхній-правий = «power posts»: і зберігають, і пересилають (найсильніші сигнали 2026). Розмір = охоплення.
/// Аудиторія — якість і досяжність

Реальна досяжна аудиторія = середнє охоплення поста / підписників. Низька reach-rate при великій базі — типовий підпис giveaway-аудиторії (частина підписників сплячі). Тренд підписників будується щодня.

/// Найкращий час публікації
Сер. охоплення за днем × слот (Київ). Сірі комірки — мало даних (n<3), не довіряй. Цифра внизу — к-сть постів.
