📐 Загальна концепція

DreamCar Team Hub — це єдина операційна платформа команди, що покриває весь цикл від ідеї до публікації: HQ для контенту, Tasks для задач, Compress для медіа, Autopost для дистрибуції, Daily Audit для контролю здоров'я системи. Всі підсистеми працюють на спільній Supabase базі, тригерять одна одну подіями та шлють нотифікації у Telegram.

Чому так

Раніше було 4 інструменти (Notion, Trello, ручний постинг, скріни у Telegram). Хаос синхронізацій. Тепер один URL і одна Postgres-база — будь-яка дія тригерить наступну автоматично.

Як працює

Frontend (HTML/JS, GitHub Pages) → Supabase (PostgREST + Edge Functions) → GitHub Actions (heavy workers — ffmpeg, Cloudflare R2) → Telegram (bot delivery). Усе event-driven.

Ключовий принцип

Робота тікає сама. Користувач робить рішення (approve/reject/post). Система робить рутину (compress, upload, postpone, notify, retry).
