Прив'язка TG → SMM акаунту

Щоб отримувати DM нотифікації, треба прив'язати TG до свого SMM акаунту:

  1. Відкрий @dreamcar_team_bot
  2. Натисни Start (або напиши /start)
  3. Бот покаже tg_chat_id і інструкцію
  4. У SMM (team.dreamcar.ua/hq/) клацни на свій профіль → "Прив'язати TG"
  5. Введи код підтвердження

AI Task extraction з командних чатів

Якщо чат у whitelist (через /listen_here), бот:

  1. Зберігає всі повідомлення у tg_chat_buffer (7 днів)
  2. Кожен ранок 09:00 Київ — Claude Haiku scan через tg-daily-task-scan
  3. Пропозиції задач шлються CEO/COO у DM з кнопками accept/dismiss/edit

Тригер inline створення (миттєво)

Додай 📌 у кінець повідомлення → бот одразу запропонує створити задачу:

Troubleshooting

Бот не відповідає на /start

  1. Перевір що tg-webhook ACTIVE: list_edge_functions
  2. Перевір webhook: https://api.telegram.org/bot<TOKEN>/getWebhookInfo → pending_update_count = 0?
  3. Перевір logs edge fn за останні 5 хв

Callbacks не працюють ("Невідома дія")

  1. Handler може бути не deployed. Перевір останню версію tg-webhook
  2. Можливо emoji з variation selector U+FE0F — checkSwitch на старі emoji
  3. Logs покажуть який саме callback_data приходить

Команди для CEO/COO заблоковані

Деякі actions (taskprop:accept, listen_here) обмежені до ceo/coo ролей. Перевір users.role у БД.
