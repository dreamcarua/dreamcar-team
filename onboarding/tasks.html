TASKS — задачі команди

Все що НЕ публікація: операційні задачі, бюджети, продакшн, переговори, баги. P1-P4 пріоритети, subtasks, recurring, watchers, аналітика.

📐 Що це і навіщо

Tasks — це персональний todo + командний пайплайн в одному. Раніше задачі тонули у TG-чатах та email. Тепер кожна задача має одного власника, дедлайн, пріоритет, watchers і автоматичні TG/email-нагадування.

Інтегровано з HQ: коли пост повертають на доопрацювання — задача створюється автоматично.

Чому так

HQ — для контенту. Asana/Trello — overkill. Trello free не має SLA timer / повторюваних. Своя система ідеально лягає під DreamCar flow.

Як працює

Та сама Supabase. Таблиці team_tasks, team_task_comments, team_task_notifications. Edge Functions для cron і delivery.

Ключове

Pull-model. SLA timer + TG-нагадування -10 хв + escalation на overdue.

🏗 Архітектура

tasks/index.html (Kanban + List + Analytics) │ ↓ PostgREST team_tasks + team_task_comments + team_task_notifications │ ↓ trigger enqueue team-tasks-cron → team-tasks-notify Edge Fns │ ↓ Resend SDK + TG Bot API TG + Email

🎯 Use cases

Будь-хто

Створити задачу

  1. Tasks → «+ Нова задача»
  2. Заголовок на дію («Зробити Х», «Спитати у Y»)
  3. Assignee, watchers, priority, due_date
  4. Опис, теги, subtasks (чек-боксики)
  5. Save → assignee одразу отримає TG ping
💡 Recurring: 'daily' | 'weekly' | 'monthly' — система авто-створить наступну.
Lead / COO

Templates повторюваних задач

  1. Tasks → Templates → «+ Новий шаблон»
  2. Опиши задачу що повторюється
  3. Default: priority, assignee, due offset, watchers
  4. «+ Нова з шаблону» — все заповнено
Member

Закрити задачу

  1. Клік на задачу → Overview модал
  2. «Розпочати» → status: doing (timer пішов)
  3. Коментарі + субтаски
  4. «Завершити» → status: done
  5. Якщо recurring — наступна автоматично
💡 TG inline: ✅ Виконано / 💬 Коментар / ⏰ +1d прямо з нотифікації.
Lead

Bulk actions

  1. Tasks → виділи кілька (checkbox)
  2. Bulk toolbar знизу: Move / Assign / Priority / Tag / Delete
CEO

Saved filters (presets)

  1. Налаштуй фільтр (P1+P2 active, не мої)
  2. «Зберегти як preset» → ім'я
  3. Наступного разу клік — той самий вигляд
💡 Дефолтний preset «Що горить» = overdue + P1 + assigned to me.

⚙️ Ключові фічі

  • Status: todo → doing → done (+ blocked / cancelled)
  • Priority: P1 / P2 / P3 / P4 (кольорові точки)
  • Subtasks: JSONB список чек-боксів
  • Recurrence: daily / weekly / monthly auto-create
  • Dependencies: depends_on задача-блокатор
  • Watchers: отримують всі сповіщення
  • Comments: @mention з TG-push
  • SLA timer: -10 хв + overdue escalation
  • Email + TG: подвійна доставка через Resend SDK
  • Bulk multi-select toolbar
  • Saved filter presets
  • Stuck-task detector: алерт якщо doing >7 днів
  • Auto-task on HQ rework: DB trigger

📊 Аналітика

/tasks/analytics.html — окремий dashboard:

  • KPI: усього / active / done за період / прострочених
  • Chart: задачі по днях (created vs completed)
  • P1/P2/P3/P4 distribution
  • Per-assignee load — хто чим зайнятий
  • Avg time-to-done
  • Bottleneck detection: задачі що довго сидять у doing
