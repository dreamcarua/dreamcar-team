📐 Що це і навіщо

CEO не має «лізти у HQ» щоб дізнатися чи всі живі. Тепер — приходить summary щоранку + у будь-який момент /audit у боті.

Бот = «командна лінія» через TG. Все що часто потрібно — інлайн-командою.

Чому ранок 7:00

CET робочий день. CEO бачить health score + критичні issues до того як відкрив laptop.

Як працює

pg_cron 5:00 UTC (=7:00 CEST) → daily-health-audit Edge Function → метрики з 6 таблиць → email через Resend + TG DM.

Health score

0-100. Алгоритм: 100 − (red×10 + yellow×3). 🟢90+ ОК, 🟡70-89, 🔴<70.

🩺 Щоденний health-report

Що включає

  • 📊 Score: 0-100 з кольоровим індикатором
  • ✍️ Публікації: усього, створено 24h, опубліковано 24h, по статусах
  • ✅ Задачі: активних, P1+P2, закрито 24h, прострочених
  • 🖼 Креативи: photo/video, pending/processing/ready/failed
  • 🚀 Автопостинг: pending/processing/done 24h/failed 24h
  • 👥 Команда: active, з auth, з TG (з іменами без)
  • 🔔 Нотифікації: створено / TG / Email доставлено
  • ⚠️ Issues: red + yellow з action hints

Доставка

Email: AUDIT_RECIPIENT через Resend з DreamCar brand HTML.
TG DM: на TG_CHAT_ID CEO через @dreamcar_team_bot. Скорочена версія.

💬 Команди бота @dreamcar_team_bot

/audit

Тригерить health-audit вручну. Звіт за ~3-5 сек.

/today

Що заплановано публікувати сьогодні.

/late

Прострочені публікації + задачі.

/my

Що чекає від мене: pubs на approval + tasks мені.

/queue

Черга всіх постів у review.

/approve

Інтерактивна черга. Бот показує по 1 публікації з inline ✅ / ↩.

/reject

Аналогічно, двокроковий: причина → confirm.

/tasks

Твої active задачі з inline «Done», «Snooze», «Comment».

🎯 Use cases

CEO

Перевірити стан системи без HQ

  1. У TG → @dreamcar_team_bot
  2. /audit
  3. За 3-5 сек — health-report
💡 Якщо score < 70 — у звіті action hints.
CEO у поїздці

Погодити пости через бот

  1. /approve у боті
  2. Бот показує публікацію (текст + creative preview)
  3. ✅ Погодити або ↩ Повернути
  4. Наступна автоматично
  5. «Все! Чисто.» коли черга порожня
Member

Закрити задачу не відкриваючи Tasks

  1. TG нотифікація → під нею inline кнопки
  2. «✅ Виконано» → status: done
  3. «💬 Коментар» → у відповідь → коментар
  4. «⏰ +1d» → due posuwa
