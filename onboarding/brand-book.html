BRAND BOOK

Як виглядає DreamCar, як говорить, що пише, що не пише. Voice linter, color checker, шаблони email/постів, фоту-бриф. Все під рукою — не треба думати «як це у нас».

● LIVE · ~25 стр PWA
Швидко: Концепція Розділи Інструменти Use cases

📐 Що це і навіщо

Brand Book — це не «що відомо», а «що використовується». Він живий, у репо, постійно оновлюється. Будь-який новий копірайтер, дизайнер, SMM відкриває одну URL і за 30 хвилин знає що робити.

Особливість: інтерактивні tools (Voice Linter, Color Checker, Brand Post Generator) — не просто читаєш правила, а тестуєш свій матеріал в реальному часі.

Чому жива

PDF брендбуки помирають за 2 місяці. Web — оновлюємо за 5 хв, нова версія у всіх одразу.

Як використовується

Перед публікацією — Voice Linter на тексті. Перед дизайном — Color Checker на палітрі. Не зрозуміло як — Component Storybook покаже.

Ключове

Voice rules захардкожені у системі per-проект: AI Copy для snEco/Barpi не пише «NASA технологія», AI Copy для DreamCar не сипле «квитками/розіграшами». Брендбук — джерело для людей, плюс джерело для AI.

📚 Ключові розділи

  • Quickstart — 15 хв, що треба знати ASAP
  • Логотип — варіанти, відступи, what NOT to do
  • Кольори — palette (DreamCar Red #E30613, Black #0A0A0A, etc), accessibility ratios
  • Типографіка — Oswald (heading), Manrope (body), JetBrains Mono (techical)
  • Voice & Tone — як ми говоримо: коротко, точно, без води. Per-проект обмеження: «NASA» заборонено у snEco/Barpi (власна патентована технологія), «квиток/лотерея/розіграш» заборонено у DreamCar (юридичні ризики).
  • Examples — добре/погано на реальних кейсах
  • Photography Brief — як знімати креативи, ракурси, освітлення
  • Mobile/PWA — як оптимізувати для маленьких екранів
  • Email шаблони — promo / newsletter / transactional (eSputnik-compatible)
  • Onboarding — як вводити нових людей
  • Регламент — workflow для команди (хто, що, коли)

🛠 Інтерактивні tools

Voice Linter

Вставляєш свій текст + обираєш проект (snEco / Barpi / DreamCar / Abris Art) → миттєвий аналіз: знайдені заборонені слова per-проект (snEco/Barpi: «NASA», DreamCar: «квиток/лотерея/розіграш»), оцінка тональності, рекомендації по змінам. Без AI, чистий JS.

Color Checker

Вставляєш свій палітр → автоматичний WCAG AA/AAA contrast check + рекомендації які пари не дружать.

Brand Post Generator

Вибираєш формат (Instagram / Facebook / TG / Email) → отримуєш кістяк поста з нашими шаблонами тексту, місцями для CTA, картинки. Експортуєш у HQ як draft.

Component Storybook

Кнопки, картки, форми, статуси — все в одному місці з CSS code. Можна копіювати у свій проект.

PWA Install

Брендбук можна «встановити» на телефон як апку — швидкий доступ.

🎯 Use cases

SMM / Copywriter

Перевірити тон публікації перед HQ submit

  1. Brand Book → Voice Linter
  2. Paste свій текст
  3. Якщо є флаги — править
  4. Якщо ✅ — копіюй у HQ → готово
Дизайнер

Створити асет на брендфоні

  1. Brand Book → Логотип → завантажити SVG/PNG версію
  2. Brand Book → Кольори → копіюй HEX
  3. Brand Book → Типографіка → завантажуй шрифти
  4. Brand Book → Photography Brief → референси
Новий копірайтер

За 30 хв навчитися писати у нашому стилі

  1. Quickstart (5 хв)
  2. Voice & Tone (10 хв) — read
  3. Examples (10 хв) — добре vs погано
  4. Voice Linter (5 хв) — потестити на свому пробному тексті
