BRAND BOOK

Як виглядає DreamCar, як говорить, що пише. Voice linter, color checker, шаблони, фоту-бриф. Все під рукою — не треба думати «як це у нас».

● LIVE · ~25 стр PWA
Швидко:КонцепціяРозділиІнструментиUse cases

📐 Що це і навіщо

Brand Book — не «що відомо», а «що використовується». Він живий, у репо, постійно оновлюється. Новий копірайтер відкриває одну URL і за 30 хв знає що робити.

Особливість: інтерактивні tools (Voice Linter, Color Checker, Brand Post Generator) — не просто читаєш правила, а тестуєш свій матеріал.

Чому жива

PDF брендбуки помирають за 2 місяці. Web — оновлюємо за 5 хв, нова версія у всіх одразу.

Як використовується

Перед публікацією — Voice Linter. Перед дизайном — Color Checker. Не зрозуміло — Storybook.

Ключове

Voice rules захардкожені у AI Copy. Брендбук — джерело для людей + для AI.

📚 Ключові розділи

  • Quickstart — 15 хв, що треба знати ASAP
  • Логотип — варіанти, відступи, what NOT to do
  • Кольори — DreamCar Red #E30613, Black #0A0A0A, etc, WCAG ratios
  • Типографіка — Oswald (heading), Manrope (body), JetBrains Mono (tech)
  • Voice & Tone — коротко, точно, без води, без NASA, без «квитків»
  • Examples — добре/погано на реальних кейсах
  • Photography Brief — ракурси, освітлення
  • Mobile/PWA — оптимізація для маленьких екранів
  • Email шаблони — promo/newsletter/transactional (eSputnik)
  • Onboarding — як вводити нових
  • Регламент — workflow для команди

🛠 Інтерактивні tools

Voice Linter

Вставляєш свій текст → миттєвий аналіз: заборонені слова, тональність, рекомендації. Без AI, чистий JS.

Color Checker

Вставляєш палітр → WCAG AA/AAA contrast check + рекомендації.

Brand Post Generator

Вибираєш формат (IG/FB/TG/Email) → кістяк поста з шаблонами і CTA. Експортуєш у HQ як draft.

Component Storybook

Кнопки, картки, форми, статуси — все з CSS code. Копіюй у свій проект.

PWA Install

Брендбук як апка на телефоні — швидкий доступ.

🎯 Use cases

SMM / Copywriter

Перевірити тон публікації

  1. Brand Book → Voice Linter
  2. Paste текст
  3. Якщо флаги — править
  4. Якщо ✅ — копіюй у HQ
Дизайнер

Створити асет на брендфоні

  1. Brand Book → Логотип → SVG/PNG
  2. Brand Book → Кольори → HEX
  3. Brand Book → Типографіка → шрифти
  4. Brand Book → Photography Brief → референси
Новий копірайтер

  1. Quickstart (5 хв)
  2. Voice & Tone (10 хв)
  3. Examples (10 хв)
  4. Voice Linter test (5 хв)
