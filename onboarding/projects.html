ПРОЄКТИ — запуски (launches)

Управління запусками: ВОЛЬВО ХС90, BMW X5 Hybrid, iPhone 17 PRO MAX тощо. Винесено з SMM у Phase 1/2 (06.06.2026) у окрему систему.

Концепція

ПРОЄКТ = запуск конкретного автомобіля чи призу. Кожен проєкт має life-cycle (анонс → продаж токенів → фінал → переможець) і пов'язані ресурси: публікації, retention розсилки, аналітику, креативи.

До Phase 2 запуски лежали всередині SMM як вкладка. Тепер це окрема система щоб не перевантажувати SMM і дати проєкт-менеджеру (Vadym/Vova) виділений простір.

Доступ

URL: team.dreamcar.ua/projects/

Структура БД

Таблиця public.launches. Ключові колонки:

  • id — UUID
  • title — назва ("ВОЛЬВО ХС90", "BMW X5 Hybrid")
  • code — короткий код ("VOLVO", "BMW_X5", "IPHONE")
  • start_at, end_at — період запуску
  • status — draft / active / finished / cancelled
  • team_lead_id — FK на users (хто веде)
  • target_revenue, target_signatures — KPIs
  • cover_image_url — обкладинка

Зв'язки з іншими системами

  • Publications (SMM) — у формі pub є dropdown "Зв'язаний із запуском". FK publications.launch_id.
  • Retention messages — теж може бути прив'язана до launch для ROI аналітики.
  • Tasks — задача може бути в контексті launch (project_id).
  • Dashboard — окрема секція "ROI per project" у дашборді. Materialized view mv_dashboard_projects_stats.

Views

  • Список — таблиця всіх launches
  • Kanban — drag-and-drop по статусам (draft / active / finished)
  • Календар — гантт-діаграма по дата діапазонам
