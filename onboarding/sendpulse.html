/// SYSTEM · CRM

SENDPULSE ІНТЕГРАЦІЯ

CRM для управління клієнтською базою DreamCar. Усі ліди з webhook'ів SendPulse летять у dashboard_deals (Supabase). SendPulse MCP офіційно підключений як data source для Claude — READ-ONLY.

🔴
HARD RULE — SendPulse READ-ONLY. Жодних змін через API/MCP — тільки GET/list. Заборонено DELETE, PUT, PATCH, POST-create. SendPulse — це жива продакшн-CRM, помилка може зруйнувати клієнтську базу 30-40K людей.

01 Що в SendPulse

SendPulse — центральна CRM DreamCar для:

  • Лідів і угод (CRM Deals)
  • Email-розсилок (transactional + promo)
  • Chatbots (Telegram + Web)
  • SMS / Viber кампаній
  • Phone бази (50 358 UA номерів станом на 30.05.2026)

02 Інтеграції

Webhook → Dashboard
Edge Function webhook-dashboard-sendpulse → INSERT у dashboard_deals. Triggered on pipeline change / deal paid.
MCP for Claude
URL: https://mcp.sendpulse.com/mcp. Auth: headers X-SP-ID / X-SP-SECRET (з https://login.sendpulse.com/settings/#api).
MCP scope
CRM / Email / Chatbots / SMTP. Усе read-only.
Dashboard data
dashboard_deals (201k+ rows) — single source of truth для аналітики. Realtime push через WebSocket subscription.
UTM mapping
Створюємо dashboard_utm_mapping rules для класифікації трафіку. matching по utm_source/utm_campaign.

03 Phone export 50K (30.05.2026)

Експорт 50 358 українських номерів виконано 30.05 з SendPulse Address Book. Дані використовуються для:

  • Custom Audience у Meta Ads (для lookalike)
  • Viber кампаній (з власного провайдера)
  • Re-engagement campaigns

Особисті дані: тримати у secure storage, НЕ публікувати у репо. Доступ лише у Вадима, Артема, маркетологів.

05 Troubleshooting

Webhook не приходить
Перевірити SendPulse Settings → Webhooks: чи URL = https://wotghlaehnvxyeacznvv.supabase.co/functions/v1/webhook-dashboard-sendpulse
MCP не авторизується
Перевірити X-SP-ID / X-SP-SECRET у Claude settings. Регенерувати у SendPulse → Settings → API
Pipeline event не парситься
Перевірити Edge Function logs (supabase functions logs webhook-dashboard-sendpulse)
Хочеться оновити запис
🛑 СТОП. SendPulse READ-ONLY. Якщо треба змінити стан у Dashboard — оновлювати dashboard_deals напряму у Supabase з audit log.
